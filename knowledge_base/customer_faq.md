# Customer FAQ — Demo Version

**All products, prices, availability, and business details are synthetic portfolio data.**

## How do I check a phone's price?
Give the assistant the product name or SKU. It should query the approved price table, check the timestamp and status, then quote the price in naira only if it is current enough.

## Can the assistant recommend a phone?
Yes. It should ask about budget, preferred operating system, storage, battery, camera, and intended use as needed. It should recommend only products found in the catalogue and distinguish recorded specifications from general guidance.

## Is a product in stock?
The assistant should query the inventory table. If inventory is missing or stale, it must say availability needs confirmation.

## Can I return a product?
The demo policy uses a seven-calendar-day initial return-request window for eligible items. It is not a universal legal rule. The assistant should gather the basic issue and escalate eligibility decisions or exceptions.

## Can you confirm my transfer?
Only if a trusted payment/order system confirms it. A screenshot or customer statement alone is not proof.

## Can I speak to a person?
The assistant should initiate the configured handoff workflow. It must not claim a person was notified until the handoff succeeds.

## Are these real prices?
No. This repository is a fictional demonstration project and all catalogue prices and stock values are synthetic.
